# 同房间多条工作线完成（D1–D8）

同一间房里多条忙的工作线先后完成时，画面按 `completedAt` 从早到晚投影「原问题引用 + 回复」。`working` 占位去掉，草稿不和已贴出的正文各画一份。视口如果贴在底部，停在最先完成的那条上，后面完成的堆在下面，不追最新一条。用户已经上滚时，顺序和占位照样更新，`scrollTop` 不动。

会话日志只追加。重排是投影，不改已经写下的工具结果，也不改 DSH 会话事件。完成后工作线回到 idle，`closedAt` 仍空。

| ID | 场景 | 期望 |
| --- | --- | --- |
| D1 | 同一间房 A 先完成，B 后完成 | 显示顺序 A 然后 B（`completedAt` 升序），每条带上原来的问题 |
| D2 | 完成之后 | `working` 行没了；草稿不和已贴出的正文重复 |
| D3 | 完成时视口贴在底部 | 最先完成的留在视口里；后面的在下面；视口不跳到最新一条 |
| D4 | 完成前用户已经上滚，条目在屏幕外 | D1 和 D2 仍成立；`scrollTop` 不变 |
| D5 | 只有一条完成 | 不拿它去跟无关消息重排 |
| D6 | 完成发生在另一间房 | 当前房间的滚动不变 |
| D7 | 同一个 `exchangeId` 的 `turn/end` 来两次 | 只投影一对引用和回复 |
| D8 | 引用文字 | 用这条线 `quote` 指到的用户原句，不用截短的标题 |
