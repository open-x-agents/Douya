# Douya website

Bilingual (EN / 中文) landing page for Douya / 豆芽, a desktop personal assistant. Warm-glass (浅暖) styling. GitHub Pages is served from this folder.

The Douya mark in `img/logo.svg` (and the derived PNG/ICO sizes) is the same bean-and-sprout used by the desktop app icon (`desktop/build/icon.png`) and the in-app sidebar. The hero is an interactive UI demo (`demo.css`, `demo.js`) of Today, Chat, Recall, Future, Settings, and the first-run wizard, with prepared replies and no network. `img/today.jpg` is the no-JS fallback and the still used in the README, which links to the live demo.

The Core features grid lists five things Douya does for a first-time visitor: Today, My Day timetable, Chat with confirm-before-send, Recall, and Future plans. The first-run wizard lives only in the demo (and a short First launch section), not in that grid. Developer setup stays in the root README, linked from a short “For developers” line.
